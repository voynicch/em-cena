Sobre o Em cena

O que é

Uma coleção pessoal para guardar o que você quer ver, o que já viu e quanto cada título valeu. Filmes, séries, programas de TV e documentários em um só lugar.

De onde vêm os dados

  • TMDB: fonte principal quando conectado. Fornece informações, capas e a disponibilidade em serviços de streaming.
  • Wikipedia, TVmaze e iTunes: fontes alternativas de busca quando o TMDB não está conectado.
  • JustWatch: origem dos dados de "Onde assistir", entregues pelo TMDB. Os catálogos podem mudar.

Seus dados

A coleção fica salva neste navegador. Se você ativar o backup do Google Drive, uma cópia também fica em um arquivo no seu Meu Drive, acessível só por você. As capas são carregadas por links externos. Em Configurações você também pode exportar a lista manualmente.

Backup da coleção

Backup automático no Google Drive

Guarda um arquivo JSON no seu Meu Drive com a coleção, as avaliações e o que você já assistiu. Use o mesmo ID em outros aparelhos para trazer a lista de volta. O Google pedirá autorização neste navegador. O token do TMDB não é enviado.

Conexão com o TMDB

Em Configurações de API do TMDB, copie o API Read Access Token e cole abaixo. Ele será enviado somente à API do TMDB e será salvo neste navegador para continuar conectado após atualizar a página. Não é incluído no backup. Use Desconectar para removê-lo.
